# 作業場所の repository に積んだ commit

main の版は `start/` にある。作業 branch `feature/range-list` は、main から次の commit を一つ積んでいる。変えたのは `booking.py`（`bookings_in_range` を足した）と `tests/test_booking.py`（`test_in_range` を足した）だけで、版は `feature/` にある。

件名「会議室ごとに期間の予約の一覧を返す」。本文は「画面の週の予約のために、開始日と終了日を含む期間の予約を利用日の順に返す関数を足す。」である。

PR の本文と review comment は、GitHub から取れないので、手元の `review/pr.md` と `review/comments.md` に写して渡した。このディレクトリの `review/` にある同じファイルである。
