# 送料の競合に固有の条件

base の main は、送料の税込への換算を送料の計算に寄せ、呼び出し側では税を足さないことにし、請求書の明細を足した。作業 branch は、商品の合計が一定額以上の注文の送料を無料にするため、送料の計算に商品の合計を渡すようにした。請求書の明細は base だけが足したファイルなので、Git は競合と判定しない。

### shop-no-double-tax

重み: 3

`out/shop/pricing.py` と `out/shop/checkout.py` を読んで判定する。

PASS：送料に税が一度だけ掛かる。送料の計算が税込を返し、支払額の計算は送料にもう一度税を掛けていない（またはその逆で一か所に寄せ、どこでも一度だけである）。送料無料の条件に当たるとき、支払額に送料が入らない。

FAIL：送料に税が二重に掛かる、送料が税抜のまま支払額に入る、または送料無料の条件が支払額に効いていない。

### shop-invoice-follows

重み: 2

`out/shop/invoice.py` を読んで判定する。

PASS：請求書の明細の送料が、送料無料の条件を反映し、画面の支払額と一致する（送料の計算に商品の合計を渡している）。

FAIL：請求書の明細が古い呼び方のまま残って呼び出しが壊れている、または送料無料の注文でも請求書に送料が載る。
