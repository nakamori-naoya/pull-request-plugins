# Title

延滞料の上限を本の値段にする

# Body

長いあいだ返されなかった本で、その本の値段より高い延滞料を請求していました（#17）。1,500 円の文庫本に 90 日分として 2,700 円を請求し、利用者から「弁償したほうが安い」と苦情が来ています。2026-08 の運営会議で延滞料はその本の値段を上限にすると決まったため、この PR で `overdue_fee` をその方針に合わせます。

`overdue_fee` は、これまでどおり延滞 1 日あたり `DAILY_FEE` 円を足し上げ、その合計を `book_price` で打ち止めにします。延滞がない場合は、これまでどおり 0 円を返します。1,500 円の本では 50 日目に上限に届くので、上限の前後が壊れないよう、49 日（1,470 円）、50 日（1,500 円）、90 日（1,500 円）を test で確かめます。CHANGELOG の「未リリース」にもこの変更を書きました。

すでに請求した延滞料には、さかのぼってこの上限を当てません。請求済みの額を減らすには会計の記録と突き合わせる必要があり、#17 でもこれは会計担当と別に決めるとしているためです。そのため、この PR を入れても、過去の請求額は変わりません。

base との競合はありません。この branch を切った後に `main` へ入った貸出延長の変更（`renewals.py`）とは、触るファイルが重なりません。
