# #17 延滞料が本の値段を超える

報告: カウンター担当

長く返されなかった本で、延滞料が本の値段を上回る請求が出ている。先月は 1,500 円の文庫本に 2,700 円（90 日分）の延滞料を請求し、利用者から「弁償したほうが安い」と苦情が来た。

館の方針（2026-08 の運営会議）で、延滞料はその本の値段を上限にすると決まった。すでに請求した延滞料をさかのぼって減らすかは、会計の記録と突き合わせる必要があるので、この issue では扱わず、会計担当と別に決める。

再現したときの記録:

```
$ python3 -c "from loans import overdue_fee; print(overdue_fee(90, 1500))"
2700
(/Users/counter-staff/work/library で実行)
```
