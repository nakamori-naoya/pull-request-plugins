# 作業場所の repository に積んだ commit

分かれ目の版は `start/` にある。main はその後に `main-next/renewals.py` を足す commit（件名「貸出の延長の可否を足す」）で進んでいる。作業 branch `feature/overdue-cap` は、分かれ目から次の commit を一つ積んでいる。版は `feature/` にある。

件名「延滞料の上限を本の値段にする」。本文は次のとおり。

> #17 の苦情を受け、館の運営会議の方針に合わせて、延滞料をその本の値段で打ち止めにする。50 日で 1,500 円の本の値段に届く境目を test で守る。すでに請求した延滞料にはさかのぼって上限を当てない。請求済みの額は会計の記録と突き合わせる必要があり、#17 でも別に決めるとしているからである。

作業ツリーには、Git の管理から外した `.env`（中身は `dot-env`）がある。
